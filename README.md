# 📚 교육자료 신청

교육을 받은 후 간단한 설문을 통해
수강생의 의견을 수집하고 교육자료 개선에 활용할 수 있는 웹앱입니다.

## 💡 프로젝트 소개

오늘 진행된 교육에 대한 수강생의 의견을
5개의 간단한 설문 문항으로 수집합니다.

설문이 완료되면 응답 내용은 Google Spreadsheet에
자동으로 저장되도록 제작했습니다.

## 🛠 사용 기술

- HTML
- CSS
- JavaScript
- Google Apps Script (GAS)
- Google Spreadsheet
- GitHub

## 📋 설문 내용

1. 오늘 교육의 난이도는 어땠나요?
2. 가장 도움이 되었던 부분은 무엇인가요?
3. 교육의 진행 속도는 어땠나요?
4. 앞으로 어떤 교육자료가 가장 필요하다고 생각하나요?
5. 교수님께 남기고 싶은 말이 있나요?

## ⚙️ 주요 기능

- 5단계 설문 화면
- 객관식 문항
- 주관식 의견 작성
- Google Spreadsheet 데이터 저장
- 설문 완료 메시지 표시
